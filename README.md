# 图灵审讯 · 七牛灵矽语音游戏

已确定首版方向：单玩家、单 AI 审讯官、一个预置案件。玩家按住说话接受盘问，AI 调证据、指出矛盾，最终生成结案报告。目标局长约 3–5 分钟。

当前处于开发前设计阶段，尚未实现应用或完成平台实测。
